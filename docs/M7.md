# M7 — multi-hub profiles

## Delivered

Config schema v2:

```jsonc
{
  "version": 2,
  "activeHub": "matrix2305",
  "hubs": {
    "matrix2305": { "url": "https://matrix2305.tailbd26da.ts.net", "passwordRef": "keychain:opencode-matrix2305" },
    "work":       { "url": "https://work.example", "passwordRef": "secret:opencode-work" }
  },
  "hub": { "url": "...", "passwordRef": "..." }
}
```

- `hub` mirrors `hubs[activeHub]` for compatibility/simple `ensureConfig`.
- Legacy v1 configs (single `hub`) are normalized in memory and saved as v2 on
  the next `saveConfig`.
- Hub names are slugged (`a-z0-9._-`); the active hub's data lives in
  `~/.local/share/opencode-node/hubs/<slug>/`:
  - `snapshot.json`
  - `applied.json`
  - `skills/<id>/SKILL.md`
- Pre-multi-hub `snapshot.json`, `applied.json` and `skills/` are moved into the
  active hub directory once (`ensureHubData`).
- Local `agents/`, `commands/`, `~/agents` and `opencode.jsonc` are shared; the
  active hub's pull overwrites them (with backups).

CLI:

```bash
oc-node hub list
oc-node hub add work --url https://work.example --password-ref secret:opencode-work [--use]
oc-node hub use work [--pull]
oc-node hub remove work [--purge]
oc-node init --hub <url> --hub-name matrix2305 ...
oc-node status    # active hub + all hubs
```

TUI: footer shows `node:<hub>` only when more than one hub is configured;
the status dialog always shows the active hub name.

## Verified

- Legacy real config migrated to `activeHub: matrix2305`, data moved to
  `hubs/matrix2305/`; `snapshot` and `applied` load correctly.
- `hub add/use/remove` round-trip on the real config.
- `oc-node pull` writes to the active hub's directory.
- Unit tests for legacy normalization, multi-hub active selection and isolated
  data dirs (15 total).

## Notes

- Switching hubs requires `oc-node pull` (or `--pull` on `use`) and a restart for
  a clean plugin reload; the RPC/TUI status updates immediately.
- Hub removal deletes only config unless `--purge` is passed.
- `src/index.ts` is a local-development shim re-exporting `dist/index.js`; a
  running OpenCode server that cached `src/index.ts` keeps working across
  reloads. The published package resolves `.` to `dist/index.js`.
