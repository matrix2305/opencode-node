# M6 — live TUI footer

## Delivered

- `src/tui.tsx` now renders a footer status via
  `context.ui.slot({ append: "home.footer.status" })`:
  `node 9s · 62m` (skills · memory files; `↑` suffix when memory is pending).
- Reactive Solid signal driven by:
  - initial `rpc.status({})`,
  - RPC `updated` events (`sync`, `push`, `config`),
  - 30 s poll as a fallback.
- Peer dependencies added:
  - `@opentui/core >= 0.8.4`
  - `@opentui/solid >= 0.8.4`
  - `solid-js >= 1.9.0`
- JSX build: `jsx: "automatic"`, `jsxImportSource: "@opentui/solid"`;
  `@opentui/*` and `solid-js` stay external (provided by OpenCode).
- TUI diagnostics: RPC errors are appended to
  `~/.local/share/opencode-node/tui.log` (no silent-only failure).
- Palette commands and toasts from M4 stay.


matches RPC (`skills 9`, `memory 62`).

## Notes

- The footer is text-only; no navigation/click actions.
- `home.footer.status` is the built-in footer row; `prompt.footer.status` can be
  added later for session view.
- TUI plugins load in the terminal client; a restart is required after
  upgrading the package in place.
- The package tarball stays small because OpenTUI/Solid are peers.
